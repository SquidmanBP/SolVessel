# Three Vessels — mod log

Hollow Knight (host) mashup: swap between the Knight, Hornet (from the player's Silksong) and Yi (from the
player's Nine Sols) at any bench. Design source of truth: `sheets/*.json`. Run `tools/preflight.ps1` before
every build.

## Installs on the dev PC (Steam, C:\Program Files (x86)\Steam\steamapps\common)
| Game | Folder | Unity | Backend | Steam build |

| Hollow Knight | Hollow Knight | 2020.2.2 | Mono | 20231655 (Modding API 1.5.78 already installed + many mods) |

## Where the content lives
### Silksong (Addressables bundles, type trees ON)
- `aa/StandaloneWindows64/herocollections_assets_shared.bundle`: GameObject "Hornet Cln" ->
  tk2dSpriteCollectionData (1828 defs, 4x 4096² BC7 atlases, texel 1/64).
- `herodynamic_assets_all.bundle`: GameObject "Hornet Anim" -> tk2dSpriteAnimation (535 clips). Clip names
  largely equal HK's (Idle, Run, Dash, Airborne, Slash, SlashAlt, UpSlash, Land, Wall Slide, Sprint...).
- `heroloading_assets_all.bundle`: HeroController MonoBehaviour with RUN_SPEED 8.25, JUMP_SPEED 18.6,
  DASH_SPEED 28, ... (same field names as HK's HeroController).
- `dataassets/herocontrollerconfigs.bundle`: "Default" config: attackDuration 0.35, attackCooldownTime 0.41...
### Nine Sols (single packed data.unity3d, 2.7 GB, LZ4HC 128 KB blocks, type trees OFF -> classdata.tpk)
- Read with BlockStream (random-access block decompression), never unpacked.
- resources.assets: AnimatorController "PlayerSpriteHolder" (218 clips: Idle, Run, Attack, Attack2, Attack3,
  AirAttack.., Parry_0.., DashRollDodge, Heal, WallSlide, WallJump, AirJump, Shoot, ...).
- Clips: sprite curve = genericBinding typeID 212 (SpriteRenderer) customType 23, isPPtrCurve 1, in the
  streamed clip's discrete curves; pptrCurveMapping -> Sprites in resources.assets.
- Sprites: tight meshes (e.g. 38 verts), PPU 8, 512² rects, one SpriteAtlas per animation
  ("HoHoYee_Standingidle_master_atlas"); render data in atlas m_RenderDataMap keyed by m_RenderDataKey.

## Route
HK Modding API mod (C#, net472) + bundled converter (ThreeVesselsPrep.exe, net472) that reads the player's
own Silksong / Nine Sols files and writes a private cache (%LOCALAPPDATA%/ThreeVessels/cache): raw atlas
textures (original GPU format, no re-encode) + JSON sprite defs + clips. The mod builds tk2d collections and
animation libraries from the cache and swaps the hero's tk2dSpriteAnimator library. No game files shipped.
